Detailed Description

Core analytics engine for face/object/person detection and recognition.

Wraps OpenCV DNN detectors and an ONNX-based embedding engine, exposing both synchronous and asynchronous processing APIs. Maintains known embeddings, performs rate-limited recognition, and emits Qt signals for UI consumers.
